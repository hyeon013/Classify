# 풍속 강풍 분류

`wind_dataset.csv`의 시간별 풍속 자료를 사용해 강풍 여부를 분류하고, 2024년 12월 평가 결과를 CSV 파일로 저장합니다. 별도 패키지 설치 없이 Python 표준 라이브러리로 실행할 수 있습니다.

## 실행

프로젝트 폴더에서 실행합니다.

```powershell
python classify_wind.py
```

가상환경을 사용하는 경우:

```powershell
.\.venv\Scripts\python.exe classify_wind.py
```

입력 파일과 출력 파일은 스크립트와 같은 폴더에 있어야 합니다. 실행할 때 예측 및 평가 CSV를 새로 작성합니다.

## 데이터와 분류

입력 데이터는 `wind_dataset.csv`입니다. 필요한 열은 다음과 같습니다.

| 열 | 설명 |
|---|---|
| `forecast_time` | 예측 시각 |
| `target_time` | 정답 시각 |
| `wind_speed_ms` | 현재 풍속 (m/s) |
| `temperature_C` | 기온 (°C) |
| `humidity_pct` | 습도 (%) |
| `wind_speed_ms_1h_before` | 1시간 전 풍속 (m/s) |
| `wind_speed_ms_2h_before` | 2시간 전 풍속 (m/s) |
| `actual_wind_speed_ms` | 정답 시각의 실제 풍속 (m/s) |

실제 풍속이 **4.0 m/s 이상**이면 강풍 정답을 1, 아니면 0으로 정의합니다. 학습 구간은 2023-01-01부터 2024-12-01 이전까지이고, 평가 구간은 2024년 12월입니다. 표준화 통계량과 로지스틱 회귀 모델은 학습 구간으로만 계산합니다.

로지스틱 회귀 입력은 현재 풍속, 기온, 습도, 1시간 전 풍속, 2시간 전 풍속입니다. 클래스 가중치는 사용하지 않습니다. 동일한 모델 확률에 0.50과 0.20 판정 기준을 각각 적용합니다. 비교용 기준 예측은 항상 0과 현재 풍속이 4.0 m/s 이상이면 1인 방식입니다.

## 출력 파일

### `classification_predictions.csv`

평가 기간의 각 행에 대해 다음 내용을 저장합니다.

- 예측 시각, 정답 시각, 실제 풍속과 강풍 정답
- 현재 풍속 및 항상 0 / 현재 풍속 기준 예측
- 로지스틱 회귀 강풍 확률
- 확률 0.50 및 0.20 기준의 강풍 분류 결과

### `classification_scores.csv`

네 가지 예측 방식(항상 0, 현재 풍속 기준, 로지스틱 회귀 0.50, 로지스틱 회귀 0.20)의 평가 행 수, 적중, 놓침, 오경보, 정상판정, 정확도, 정밀도, 재현율을 저장합니다. 강풍 예측이 없는 경우 정밀도는 `해당 없음`으로 기록됩니다.

### `strong_wind_december.png`

12월 1~7일의 실제 풍속 및 강풍 분류를 정답 시각(KST)에 맞춰 그린 그래프입니다. 위 패널은 실제 풍속과 4.0 m/s 기준선, 아래 패널은 실제 강풍과 0.50·0.20 판정을 표시합니다. 이 그림은 별도 시각화 산출물이며 `classify_wind.py`를 실행해도 자동으로 다시 생성되지는 않습니다.
